# Quizy

A small, timed trivia game built with HTML, CSS, and vanilla JavaScript. Questions come from the [Open Trivia DB](https://opentdb.com/).

## Run it

Open `index.html` in a browser. If your browser blocks API requests from local files, serve this folder with the VS Code Live Server extension and open the local address it provides. An internet connection is needed to load questions.
